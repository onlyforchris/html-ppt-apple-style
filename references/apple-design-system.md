# Apple Keynote 设计系统参考

本文件描述苹果发布会（Keynote）风格的视觉设计规范，供 WorkBuddy 生成 HTML PPT 时严格遵循。

---

## 1. 设计哲学

| 原则 | 说明 |
|------|------|
| **Less is More** | 每页只传达一个核心信息，不堆砌内容 |
| **Drama First** | 用视觉冲击力先抓住眼球，再讲细节 |
| **Cinematic Dark** | 黑色背景是主基调，白色和亮色作为强调 |
| **Typography as Hero** | 字体本身即视觉元素，大标题、大数字就是设计 |
| **Motion & Flow** | 切换动效丝滑，元素出现有节奏感 |

---

## 2. 颜色系统

### 背景色阶（深色主题）
```
黑底:        #000000  — Hero 幻灯片、标题页
深灰底:      #0a0a0a  — 产品特写、规格页
深蓝黑渐变:  #0a0a0a → #111 → #1a1a2e  — 功能介绍页
```

### 浅色主题（间隔使用，增加节奏感）
```
苹果白:      #ffffff
浅灰:        #f5f5f7
文字色:      #1d1d1f
次级文字:    rgba(29,29,31,0.7)
```

### 强调色
```
Apple Blue:  #0071e3  — 主要按钮、链接、徽章
渐变蓝青:    #4facfe → #00f2fe  — 科技感渐变文字
渐变紫粉:    #c471ed → #f64f59  — 创意/设计感
渐变金黄:    #f7971e → #ffd200  — 价格/高亮
渐变绿青:    #43e97b → #38f9d7  — 环保/健康/正向数据
```

## 3. 字体规范

**字体栈**: `'Inter', -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'Helvetica Neue', sans-serif`

| 用途 | 大小 | 字重 | 字间距 |
|------|------|------|--------|
| 超大标题（Hero） | 96–120px | 800 | -0.04em |
| 主标题 | 72–88px | 700 | -0.03em |
| 次标题 | 48–56px | 700 | -0.025em |
| 正文副标题 | 24–32px | 300 | -0.01em |
| 说明文字 | 16–20px | 400 | normal |
| 角标/标签 | 13–15px | 600 | 0.08–0.15em (全大写) |
| 大数字统计 | 80–108px | 800 | -0.04em |

## 4. 幻灯片类型库

### 1. Hero 开场
- 纯黑背景 + 渐变光晕装饰
- 超大渐变文字标题
- 徽章（Badge）＋短 Tagline

### 2. One More Thing 公告页
- 黑底 + 戏剧性文字
- "And one more thing…" 句式
- 单一核心信息

### 3. 三列特性卡片
- 深色背景
- 每列：图标 + 标题 + 简短说明
- 统一的毛玻璃卡片效果

### 4. 大数字统计
- 黑底 + 光晕背景
- 巨大渐变数字
- 指标标签全大写小字

### 5. 产品详情（白底）
- 纯白背景，制造节奏对比
- 浅灰卡片
- 精简文字

### 6. 名言引用
- 深色背景
- 大号引号装饰
- 轻盈字重（300）的长引用文字

### 7. 价格 / CTA
- 黑底
- 大号价格（金色渐变）
- 两个按钮：主要行动（蓝色实心）+ 次要行动（半透明）

### 8. 结尾谢幕
- 纯黑背景
- 简单一个字"谢谢。"或产品名
- 配网址

## 5. 布局原则

```
幻灯片尺寸: 1280 × 720px (16:9)

安全区域内边距:
  - 正常内容: padding 80px
  - 全出血图片: 不留边距
  - 带左对齐文字: padding-left 100px

网格系统:
  - 1 列: 最大宽度 900px，居中
  - 2 列: grid-template-columns: 1fr 1fr, gap 60px
  - 3 列: grid-template-columns: 1fr 1fr 1fr, gap 40px
```

---

## 6. 交互功能（必须包含）

每个 HTML PPT 必须包含：
1. **← → 方向键** 切换幻灯片
2. **Space 键** 前进
3. **F 键** 全屏模式
4. **点击导航点** 跳转到任意页
5. **触摸滑动** 支持移动端
6. **幻灯片编号** 右下角显示 "当前 / 总数"
7. **进入动画** `slideIn` 淡入上移效果

## 7. 背景装饰规范

### 光晕 (Glow)
```css
/* 始终 position: absolute，不影响布局 */
/* 使用 filter: blur(80px) 实现柔光效果 */
/* 透明度控制在 0.15–0.25，不抢主体 */
蓝色光晕: rgba(0, 113, 227, 0.25)
紫色光晕: rgba(196, 71, 237, 0.20)
青色光晕: rgba(0, 242, 254, 0.15)
```

### 微妙纹理
```css
/* Carbon / 网格纹理 */
repeating-linear-gradient(0deg, rgba(255,255,255,0.02) 0px, ..., transparent 40px)
```

## 9. 常见反模式（避免）

- ❌ 不使用 PowerPoint 蓝/红/绿等俗艳颜色
- ❌ 不用子弹点列表塞满整页
- ❌ 不用白底配彩色表格边框
- ❌ 不用 Comic Sans、楷体等非系统字体
- ❌ 不在单页放超过 3 个核心信息
- ❌ 不用硬边阴影（box-shadow 应柔和）
- ❌ 不给背景加鲜艳色块（要渐变、要暗）

## 10. 内容密度参考

| 页面类型 | 文字量 | 视觉权重 |
|----------|--------|----------|
| 封面 / 结尾 | 极少（1–2 行） | 极高 |
| 公告 / 名言 | 少（1–3 行） | 高 |
| 特性介绍 | 中等（每卡片 2–3 行） | 中高 |
| 规格 / 数据 | 数字为主 | 高（数字） |
| 比较 / 列表 | 适中 | 中 |
